⛔ MANDATORY CONSTRAINTS — EVERY PROMPT

  1. NEVER read the full HTML into context — it's 10MB+ with base64 images. Do NOT use cat, head, tail, view, or grep on the HTML. Write a single Python script that does all edits.
  2. One script, one read, one write — the Python script reads the file into a Python variable (open(SRC).read()), performs all edits via .find(), .replace(), slicing, or re.sub(), then writes the result. Never split into multiple scripts or multiple read/write passes.
  3. Search before assuming — always search for exact strings. If a target returns 0 hits, print a warning and skip. Never guess or fabricate patterns.
  4. Preserve base64 image data — never match patterns inside data:image strings.
  5. Size check before finishing — if output file is <95% of input size, something went wrong. Print ERROR and exit.
  6. Clean up after every prompt — delete the .py script, rasterized pages, intermediate crops, old HTML versions. Only permanent project files survive.
  7. STOP on conflicts — when PDF content contradicts existing HTML, flag it. Don't reconcile. Pedro decides.
